## 1. Create an API key

Go to **Settings > API** in your [Ranked AI dashboard](https://app.ranked.ai/dashboard/settings?tab=api-keys) and create a new API key.

- **Read Only** keys can fetch all data (keywords, audits, backlinks, etc.)
- **Read + Write** keys can also create reports, manage webhooks, and update preferences

<Warning>
  API keys are shown only once when created. Copy and store it securely.
</Warning>

## 2. Find your project ID

List your SEO projects to get the project ID you need for all subsequent calls:

<CodeGroup>
```bash cURL
curl https://app.ranked.ai/api/v1/projects \
  -H "Authorization: Bearer rk_live_your_api_key"
```

```javascript JavaScript
const response = await fetch('https://app.ranked.ai/api/v1/projects', {
  headers: { 'Authorization': 'Bearer rk_live_your_api_key' }
});
const { data } = await response.json();
console.log(data);
// [{ id: "abc-123", name: "My Website", status: "active", ... }]
```

```python Python
import requests

response = requests.get(
    'https://app.ranked.ai/api/v1/projects',
    headers={'Authorization': 'Bearer rk_live_your_api_key'}
)
projects = response.json()['data']
```
</CodeGroup>

## 3. Fetch keyword rankings

Use the project ID to get your keyword positions across Desktop, Mobile, AI Mode, and Maps:

<CodeGroup>
```bash cURL
curl "https://app.ranked.ai/api/v1/projects/YOUR_PROJECT_ID/rankings/keywords?limit=10" \
  -H "Authorization: Bearer rk_live_your_api_key"
```

```javascript JavaScript
const response = await fetch(
  `https://app.ranked.ai/api/v1/projects/${projectId}/rankings/keywords?limit=10`,
  { headers: { 'Authorization': 'Bearer rk_live_your_api_key' } }
);
const { data, meta } = await response.json();

data.forEach(keyword => {
  console.log(`${keyword.keyword}: Desktop ${keyword.desktop_position}, Mobile ${keyword.mobile_position}, Net Change ${keyword.net_change}`);
});
```
</CodeGroup>
