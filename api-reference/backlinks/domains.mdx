---
title: "Referring Domains"
api: "GET /projects/{projectId}/backlinks/domains"
description: "Get referring domains with domain rank, backlink count, and follow status"
---

Returns paginated referring domains sorted by domain rank.

<ParamField path="projectId" type="string" required>Project UUID</ParamField>

<ParamField query="limit" type="number" default="50">
  Maximum domains to return (max: 1000)
</ParamField>

<ParamField query="offset" type="number" default="0">
  Number to skip for pagination
</ParamField>

<ParamField query="sort_by" type="string" default="domain_rank">
  Sort by: `domain_rank`, `backlinks_count`, or `first_seen`
</ParamField>

<ParamField query="sort_order" type="string" default="desc">
  `asc` or `desc`
</ParamField>

<RequestExample>
```bash cURL
curl "https://app.ranked.ai/api/v1/projects/{projectId}/backlinks/domains?limit=10&sort_by=domain_rank" \
  -H "Authorization: Bearer rk_live_your_api_key"
```
