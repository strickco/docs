---
title: "Latest Audit"
api: "GET /projects/{projectId}/audits/latest"
description: "Get the most recent completed audit with issue summary"
---

Returns the latest completed audit for a project with issue counts. Issue counts reflect the current state after any dismissals.

### Path parameters

<ParamField path="projectId" type="string" required>Project UUID</ParamField>

<RequestExample>
```bash cURL
curl "https://app.ranked.ai/api/v1/projects/{projectId}/audits/latest" \
  -H "Authorization: Bearer rk_live_your_api_key"
```
</RequestExample>

<ResponseExample>

{

  "data": {
    "id": "2e8b1269-d954-4b3b-a5e5-233bd44dfc28",
    "target_url": "https://siouxcitytreeco.com/",
    "status": "completed",
    "crawl_progress": 100,
